# Calculador de média de alunos

![Python](https://img.shields.io/badge/Python-3.x-blue?style=for-the-badge&logo=python)
![status](https://img.shields.io/badge/Status-Conclu%C3%ADdo-brightgreen?style=for-the-badge)

Um sistema interativo em linha de comando CLI, desenvolvido em Python, para auxiliar professores no gerenciamento de notas. O programa permite cadastrar o docente, cadastrar um aluno com suas notas, calcular a média aritmética e avaliar a situação final do estudante (aprovado ou reprovado dependendo da nota).

## 🚀 Funcionalidades

* **Cadastro do professor:** Registro inicial com nome, CNDB (Carteira Nacional Docente do Brasil) e disciplina do mesmo.
* **Gerenciamento de notas:** Cadastro de aluno (Nome e RM) e válido a entrada para 4 notas (de 0 a 10).
* **Cálculo automático:** É calculado a média aritmética das notas digitadas.
* **Consulta de Situação:** Exibe de um relatório com o status do aluno:
    * **APROVADO(A)!** para médias iguais ou superiores a 6.
    * **REPROVADO(A)!** para médias inferiores a 6.
* **Menu Interativo:** A navegação é feita por terminal, para escolha de opções inválidas.
